# Text-to-SQL-AI 🤖

An AI-powered Natural Language to SQL Query Application built using **Python, Streamlit, and Google Gemini AI**.

## 🚀 Project Overview

Text-to-SQL-AI allows users to convert natural language questions into SQL queries using AI.

The goal is to make database querying easier without requiring users to manually write SQL statements.

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini AI
- SQL
- SQLite

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/khaninjmam152/Text-to-SQL-AI.git
```

2. Navigate to the project directory:

```bash
cd Text-to-SQL-AI
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate the environment (Windows):

```bash
venv\Scripts\activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

6. Configure your Gemini API key as required in the application.

7. Run the application:

```bash
streamlit run app.py
```
